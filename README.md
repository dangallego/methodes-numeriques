# Méthodes Numériques

This repository contains a collection of Python scripts and projects developed for a university-level numerical methods course (*Méthodes Numériques*), including simulations in classical mechanics, electromagnetism, quantum mechanics, and fluid dynamics.

## Highlights

- **Final Project (Fluid Dynamics)**: Lid-driven cavity simulation and presentation ([PHYS4100 Final Project.pdf](./PHYS4100%20Final%20Project.pdf))
- **Mechanics**: Kinematics, ball drop, air resistance trajectories
- **Quantum**: Infinite square well visualizations
- **Statistics**: Brownian motion, importance sampling
- **Signal Processing**: Fourier transforms
- **Math Tools**: Derivatives, integrals, Runge-Kutta

## Files

Each script is named to reflect the topic or problem it solves. For example:
- `4-4-Calculating-Integrals.py`: Numerical integration routines
- `6-13-Infinite-SqWell.py`: Quantum well solver and plotter
- `Lid-Driven-Cavity.py`: Final project simulating fluid flow in a square cavity

## Structure

This is a flat repo with topic-specific Python files. Most files are self-contained and can be run independently using `python <filename>.py`.
